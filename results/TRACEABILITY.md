# Result Traceability

Every raw row can be traced deterministically:

```text
experiment
  -> result/<experiment>/
  -> result/<experiment>/train_val_evaluate.csv
  -> result/<experiment>/hyper_parameters.json
  -> result/<experiment>/train.log (where present)
  -> result/<experiment>/checkpoint.pth (only_omics, only_kg, and umt; not ume)
```

The `experiment` value is the exact directory basename from the archival master. The `source_result_dir` and `source_result_csv` columns in `all_380_official_experiment_results.csv` are repository-relative archival paths. The parser accepts only names matching `server_official_e200_pan_e30_<cancer>_cv_<cv>_fold_<fold>_<task_type>` and therefore cannot include the preflight directory.

To inspect a source record, use the corresponding `source_result_csv` path within the separately preserved reproduction archive. The summaries are generated by `scripts/build_summaries.py`; this script reads metrics and metadata only and never opens checkpoints for computation.

Runner provenance is independent of the result rows: `experiments/run_full_grid.py` is the recovered custom runner and its SHA-256 is recorded in `evidence/run_full_grid_sha256.txt`. The preserved official analysis text is not overwritten when the CSV-derived summary differs; the CESC CV1 UMT discrepancy is recorded in `evidence/analysis_consistency_note.txt`.
