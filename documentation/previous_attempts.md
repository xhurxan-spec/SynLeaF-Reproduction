# Previous Attempts

Earlier reproduction attempts were conducted before the final university-server run. They are not part of the official result set presented in this repository.

- Earlier attempts included reduced-epoch and different-runtime experiments. They are treated as historical context and are not included in the official result tables.
- The final university-server reproduction used the prefix `server_official_e200_pan_e30`, completed 380/380 official tasks, and is the only result set summarized under `results/`.
- The separate `preflight_BRCA_cv1_fold1_only_omics` directory validated the server environment for one epoch and is not an official task.

No earlier result is presented as evidence for completion of the official 380-task reproduction.
